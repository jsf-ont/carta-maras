# Skill Registry — Maras Carta

## Project Skills

| Skill | Purpose |
|-------|---------|
| `maras-ui-ux-audit` | UI/UX audit: responsive behavior, hierarchy, interactions, accessibility |
| `maras-design-audit` | Design audit: colors, typography, spacing, premium feel |

## Usage

When auditing the carta:
- **UI/UX audit**: "audita la UI/UX", "cómo se ve en móvil", "es user-friendly?"
- **Design audit**: "audita el diseño", "revisá los colores", "está bien la tipografía"

## Notes

- Both skills target ONLY `carta_maras.html` in the project root
- Skills are in `.agents/skills/` directory
